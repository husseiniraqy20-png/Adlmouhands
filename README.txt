تطبيق «المهندس» - حزمة التثبيت على الموبايل
============================================
1) الرفع (مرة واحدة، مجاني):
   - افتح https://app.netlify.com/drop
   - اسحب هذا المجلد (بعد فك الضغط) كاملاً إلى الصفحة.
   - ستحصل على رابط https. أرسله للموظفين.
   (بدائل: GitHub Pages أو Cloudflare Pages أو أي استضافة https.)

2) التثبيت كتطبيق على الهاتف:
   - أندرويد (Chrome): افتح الرابط ← زر «تثبيت» أعلى التطبيق، أو قائمة ⋮ ← «تثبيت التطبيق».
   - آيفون (Safari): افتح الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
     مهم: ثبّت التطبيق قبل إدخال أي بيانات، لأن تخزين آيفون يكون منفصلاً للتطبيق المثبّت.
   - اسمح بإذن «الموقع» عند أول تسجيل حضور.

3) للحصول على ملف APK (اختياري، أندرويد):
   - افتح https://www.pwabuilder.com وأدخل رابط تطبيقك ثم Package for stores ← Android.
   - حمّل الحزمة ووقّعها كما يشرح الموقع. النشر على Google Play يتطلب حساب مطوّر مدفوع.

4) عند تحديث التطبيق لاحقاً: غيّر رقم النسخة في sw.js (V='almuhandis-v2') ثم أعد الرفع.
